# Previous Year Question Papers: Idea Plan

## Core Goal

Create a fast, modern, and student-friendly portal for Lucknow University previous year papers (last 10 years), with strong filtering and clear visual hierarchy.

## Suggested Features

1. Smart search by subject, course, semester, and year.
2. One-click download/preview for every paper.
3. Latest papers section on top for quick access.
4. Stats panel showing total papers, programs, and years covered.
5. Mobile-first layout for phone users.

## Data Strategy

1. Keep all paper metadata in a single JavaScript data file.
2. Store: course, semester, subject, year, exam type, and file URL.
3. Move to JSON or API backend later when data grows.

## Visual Direction (Corporate Trust)

1. Indigo-violet gradients for brand identity.
2. Clean white cards with soft colored shadows.
3. Plus Jakarta Sans typography for readable modern look.
4. Subtle motion and reveal animations for polished UX.

## Next Upgrade Ideas

1. Add actual PDF links and file preview modal.
2. Add branch tabs (Arts, Science, Commerce, Law, Tech).
3. Add bookmark or save-for-later using local storage.
4. Add admin page for adding new papers without editing code.
5. Add backend with authentication for verified uploads.
